# StreamBERT for Android

This page holds only the Android app (APK) builds of StreamBERT.

**Install:** open the newest release below, download the `.apk` file on your
phone and open it. Android asks once whether your browser or file manager may
install apps.

**Updates:** the app looks here when it starts. When a newer version is here,
a red bar offers it. One tap downloads it, and Android's own installer
finishes the job. Your saved titles and settings stay.

**First start:** it works straight away. To sync your own watch history,
connect your own Trakt account in Settings.

**Source:** every release also carries the app's source code as a zip
(`StreamBERT-x.y.z-source.zip`).

StreamBERT is based on [truelockmc/streambert](https://github.com/truelockmc/streambert)
and, like it, is free software under the GNU General Public License v3.
